Web Hosting y dominios

Para poner una página en internet se necesita un lugar donde guardar sus archivos (hosting) y una dirección fácil de recordar (dominio).

Web Hosting

Es un servicio que guarda tus archivos en un servidor siempre encendido para que cualquiera los vea.

  • Compartido: varios sitios comparten un servidor; barato, con recursos limitados.
  • VPS: parte de un servidor reservada para ti; más control y más costo.
  • Nube: recursos repartidos en muchos servidores; crece según la demanda.

Cómo funciona Vercel con sitios estáticos

Conectas tu repositorio de GitHub y, cada vez que haces un commit, Vercel copia los archivos HTML, CSS y JS a una red de servidores por todo el mundo y te da una URL como nombre-proyecto.vercel.app.

Dominios

  • Nombre de dominio: la dirección legible del sitio, como figuritas.com.
  • TLD: la terminación, como .com, .net o .org.
  • Subdominio: prefijo antes del dominio, como tienda.figuritas.com.

Propagación DNS

El DNS traduce un dominio a la dirección IP del servidor. Al cambiarlo, puede tardar de minutos a 48 horas en actualizarse en todo el mundo.
