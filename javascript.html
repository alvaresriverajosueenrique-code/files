JavaScript (JS Vanilla)

JavaScript es el lenguaje de programación que hace que una página web responda a lo que hace la persona: clics, teclas, formularios y más. "Vanilla" significa JavaScript puro, sin librerías.

HTML, CSS y JS

Tecnología Rol Ejemplo
HTML Estructura Un botón y un título
CSS Estilo El botón es verde y redondo
JS Comportamiento Al hacer clic, cambia el texto

Conceptos básicos

  • Variables: guardan datos (let nombre = "Figuritas").
  • Funciones: bloques de código reutilizables.
  • Eventos: reacciones a acciones como click o mouseover (hover).

Ejemplo práctico

const boton = document.getElementById("regar");
let figuras = 0;

function agregar() {
  figuras = figuras + 1;
  boton.textContent = "Figuras: " + figuras;
}
boton.addEventListener("click", agregar);
