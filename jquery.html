jQuery

jQuery es una librería de JavaScript creada en 2006 para escribir menos código y resolver las diferencias entre navegadores, que entonces eran muy distintas.

Sintaxis básica

El símbolo $ selecciona elementos y se le encadenan acciones: $("selector").acción().

JavaScript vs. jQuery

Tarea JS Vanilla jQuery
Seleccionar document.querySelector(".caja") $(".caja")
Evento clic el.addEventListener("click", fn) $(el).click(fn)
Ocultar el.style.display = "none" $(el).hide()

Ventajas y desventajas

  • Ventajas: código corto, efectos listos y mucho código antiguo que lo usa.
  • Desventajas: pesa más, y el JavaScript moderno ya hace casi todo lo mismo sin librería.

Efectos típicos

$("#mostrar").click(function () { $("#caja").fadeIn(); });
$("#alternar").click(function () { $("#caja").slideToggle(); });
