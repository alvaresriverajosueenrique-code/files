JSON (JavaScript Object Notation)

JSON es un formato de texto para guardar e intercambiar datos. Es el estándar porque es ligero, fácil de leer para personas y lo entienden casi todos los lenguajes.

Estructura

  • Pares clave-valor: "nombre": "Figuritas"
  • Objetos: entre llaves { }
  • Arreglos: listas entre corchetes [ ]

Objeto JS vs. cadena JSON

Objeto JS

const figura = {
  nombre: "Robotito",
  cantidad: 3,
  rara: false
};

Cadena JSON

{"nombre":"Robotito",
 "cantidad":3,
 "rara":false}

En JSON las claves siempre llevan comillas dobles. Se convierte con JSON.stringify(objeto) y JSON.parse(texto).

JSON y las APIs

Cuando una app necesita datos, envía una petición al servidor y este responde con JSON. La app lo convierte en objetos y los muestra en pantalla.

fetch("https://api.ejemplo.com/figuras")
  .then(r => r.json())
  .then(datos => console.log(datos));
